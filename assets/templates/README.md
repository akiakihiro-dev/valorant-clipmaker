# assets/templates/

キル検出で使うテンプレート画像を置くディレクトリです。

- `own_name.png`（各自で用意・配置する。個人が特定できる情報のためリポジトリには
  含めておらず、`.gitignore`対象）: 自分のプレイヤー名をキルフィードから切り出した
  画像。詳しくはリポジトリルートの[README.md](../../README.md)を参照。

  切り出す際は、文字ギリギリではなく**上下に少し余裕を持たせて、キルフィード
  1行分の高さ（1920x1080基準で約40px）に相当する範囲で**切り出すこと。文字だけを
  ギリギリに切り出す（例: 20px程度）と、テンプレートの形の情報量が少なくなり、
  他プレイヤーの名前や数字など無関係な白文字にまで一致してしまい、キル判定が
  ほぼ常時「キル」になる誤検出が発生することを確認済み。
